# Ảnh tham chiếu giao diện

Các PNG được trích nguyên bản từ `Tài liệu/01_Phan_tich_thiet_ke_he_thong_Shinbaby.docx`.
Component `ReferenceArt` dùng các vùng ảnh riêng bằng CSS: logo, banner, sản phẩm, danh mục, avatar và ảnh đánh giá. Các nút, bộ lọc, giá, màu/size, phân trang, voucher và giỏ hàng được dựng bằng Angular để tương tác.
Ảnh sản phẩm trong mẫu có một số huy hiệu/đồ họa quảng bá được giữ cho bản demo theo yêu cầu. Mọi dữ liệu là minh họa, không xác nhận sản phẩm hoặc chính sách kinh doanh thật. URL `ref:` chỉ định vùng ảnh local, không phải URL trên mạng. Khi dùng API thật, URL ảnh thông thường được ưu tiên hiển thị.
